# Decision Mesh direction

Decision Mesh helps people see when an AI agent needs a decision, understand what is being asked, and return to the appropriate decision surface.

The first production release is planned as a reliable standalone open-source product: a local inbox, durable request history, clear evidence labels, optional notifications, and a supported installation and recovery path. This release is not yet qualified. Notification delivery, user decisions and actual agent execution remain separate states.

People should be able to choose notification timing and presentation without changing the underlying request data. First-release controls prioritize predictable behavior; broader batching, themes, remote decisions, multi-user routing and cloud services are future work, not current product promises.

Progress Mesh remains independent. A future optional integration will attach sanitized project-progress context to decisions or include pending decisions in progress updates through a versioned exchange format. Shared data storage or a mandatory combined runtime is not planned for the first standalone release.

The open-source functionality remains usable without payment. Optional community support may fund continued development. A working release, real adoption and the first genuine external donation are distinct milestones; none can be inferred from adding a funding link.
